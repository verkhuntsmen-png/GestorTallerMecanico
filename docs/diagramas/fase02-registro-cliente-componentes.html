Flujo de autenticación

Login y registro mantienen su recorrido a través de la fachada de autenticación.

Vue Login/Registro→AuthFacade→AuthService/JWT→UserRepository→MySQL

Flujo de alta de cliente

Solo una sesión con permiso CLIENTS_WRITE puede completar el alta.

Vue Cliente→JWT/RBAC→CustomerFacade→Repository + Foto→MySQL/Archivos
