Las flechas describen el protocolo usado en cada comunicacion: REST/JWT para la aplicacion, HTTP/JSON para SEPOMEX y JPA/JDBC/SQL para MySQL.

La API SEPOMEX se consulta directamente desde Vue para autocompletar direcciones. Spring Boot no mantiene actualmente un cliente interno hacia ese servicio.
